# サプライチェーン地図

業界ごとのサプライチェーン（上流から下流までの段）と、各段の代表企業、段をまたぐ会社、資本関係をまとめた地図です。業界構造の理解用で、投資判断の材料ではありません。

公開ページ: https://phystaro9.github.io/supply-chain-map/

## ファイル構成

| ファイル | 中身 | よく触るか |
|---|---|---|
| `index.html` | 見た目と動き。業界が増えても基本的に触らない | まれ |
| `industries.js` | 業界の一覧（タブの並び順） | 業界を足すとき |
| `companies.js` | 会社の共通情報。全業界で1社1件（名前・公式サイト・上場区分・数値・補足） | よく触る |
| `data/<業界ID>.js` | 業界ごとの段と、各社がどの段で何をしているか | よく触る |
| `pages/<会社ID>.js` | 企業ページ（概要・資本関係のグラフ・資本構成など） | 企業ページを足すとき |
| `prototype_electric_power.html` | 旧URLから `index.html` への転送用 | 触らない |

ページは、表示中の業界のデータを先に読み込み、残りの業界は後から読み込みます。

## URLの形

- `#power` … 電力の全体
- `#power-equipment` … 電力の「発電設備」の段
- `#power-co-jera` … 電力から見たJERAの企業ページ
- `#shipping` … 海運の全体

業界の付いていない古いリンク（`#fuel`、`#co-jera`）は、最初の業界（電力）として扱います。

## 追加の手順

**業界を足す**
1. `data/<業界ID>.js` を作る（既存の業界ファイルをまねる）
2. `industries.js` に1行足す
3. 新しく出てくる会社を `companies.js` に足す

**会社を足す**
1. `companies.js` に共通情報を足す（すでにあれば不要）
2. 出てくる業界の `data/<業界ID>.js` の `companies` に、`id`・`type`・`home`・`stages` を足す

**企業ページを足す**
1. `pages/<会社ID>.js` を作る
2. `companies.js` のその会社に `page: true` を足す

## データの決まり

- **数値は必須ではない。** 載せる業界だけ、業界ファイルで `showNumbers: true` にする
- **時価総額は月末の終値でそろえる。** 月末の値が取れない会社は、取れた日付を `capDate` に書く（ページ上で「時点違い」と表示される）
- **未上場企業は売上高で表示する。** 時価総額と同じ並びで比べるのは目安と注記する
- **金額の単位は億円。**（1兆円 = 10000）
- **不明なものは空欄にせず「未確認」と書く。**（出資額は `amount: null` で自動的に「出資額 未確認」と表示される）
- **資本関係の矢印は「出資する側 → 出資される側」。** 矢印には持ち株比率と出資額を書く
- **資本構成は簿価と時価を併記する。** 時価がないものは理由を `fvNote` に書く
- **`stages` が2つ以上ある会社は、自動で「段をまたぐ会社」の帯に出る。** 子会社が担う段も含めてよい（説明文に子会社名を書く）
- **業界をまたぐリンクは自動で付く。** 同じ会社IDが複数の業界ファイルにあれば、行に「他の業界（段）→」のリンクが出る。まだページのない業種は `companies.js` の `otherSectors` に `href: null` で書く（「準備中」と表示される）
- **事実を足すときは出典を確認する。** 社名変更・上場廃止・TOBなどは `note` に時点つきで書く
