# サプライチェーン地図

業界ごとのサプライチェーン（上流から下流までの段）と、各段の代表企業、段をまたぐ会社、資本関係をまとめた地図です。業界構造の理解用で、投資判断の材料ではありません。

公開ページ: https://phystaro9.github.io/supply-chain-map/

## ファイル構成

```
index.html            見た目（CSS）と画面の骨組み。スクリプトの読み込み順もここ
industries.js         領域（大きな棚）と業界の一覧。トップでの並び順、カードの説明、「準備中」の業界名
companies.js          会社の共通情報。全業界で1社1件
xref.js               自動生成の索引（会社 → 出てくる業界と段）。手で書き換えない
deps.js               業界どうしのつながり（領域をまたぐ線）。「供給する側 → 受け取る側」を1本ずつ
data/<業界ID>.js       業界ごとの段と、各社がどの段で何をしているか
pages/<会社ID>.js      企業ページの上乗せ分（概要・業績・資本関係・資本構成）
js/util.js            小道具（エスケープ、金額表示、読み込み、検索用の文字そろえ）
js/store.js           データの置き場と読み込み、リンクの組み立て
js/views/home.js      トップ（領域ごとの業界一覧と、準備中の棚）
js/views/network.js   つながり図（領域のかたまりと、業界どうしの線）
js/views/industry.js  業界の全体図・段をまたぐ会社の帯・段の詳細
js/views/company.js   企業ページ（全社に自動で用意）
js/app.js             起動、URLの振り分け、会社検索
tools/build.js        データの点検と xref.js の生成
prototype_electric_power.html  旧URLからの転送用
```

ページを開くと、`industries.js`・`companies.js`・`xref.js` だけを最初に読み込みます。業界のデータは表示する業界の分だけ、企業ページの上乗せ分は開いたときだけ読み込みます。業界をまたぐリンクは `xref.js` から作るので、業界が増えても読み込む量はほとんど増えません。

## 領域・業界・段

```
領域（11個）  エネルギー、運輸・物流、素材・化学、機械・重工、自動車・モビリティ、電機・半導体、
              通信・IT、商社、生活・ヘルスケア、金融、不動産・建設
  └ 業界      電力、海運 など。どれか1つの領域に入る
      └ 段    燃料・資源 → 発電設備 → … と、上流から下流への流れ
```

- **業界の切り方：** 上流から下流まで、モノかサービスが1本の流れでつながるものを1業界とする。「運ぶ」「貸す」のような機能だけで切らない
- **商社は独立した領域。** 全領域に出資する横串の存在なので、各領域には会社として顔を出す
- **金融と不動産は分ける。** 不動産はゼネコンとセットで「不動産・建設」
- **造船は機械・重工の領域の話。** いまは海運の最上流の段として載せている（三菱重工などが電力設備と造船の両方に出る）
- 領域の分け方は、迷ったら東証33業種・GICSに照らして決める

## URLの形

| URL | 表示 |
|---|---|
| `#home`（または空） | 業界一覧 |
| `#power` | 電力の全体 |
| `#power-equipment` | 電力の「発電設備」の段 |
| `#map` | 業界どうしのつながり図 |
| `#co-mhi` | 三菱重工の企業ページ |

古い形（`#fuel`、`#co-jera`、`#power-co-jera`）も受け付けます。

## データを変えたら

```
node tools/build.js
```

を実行してからコミットします。IDの書き間違い、存在しない段の指定、企業ページのファイル漏れなどがあれば、エラーを並べて止まります（`xref.js` は書き換えません）。

## 追加の手順

**業界を足す**
1. `data/<業界ID>.js` を作る（既存の業界ファイルをまねる。業界IDは英小文字と数字だけ）
2. `industries.js` の `SCM_INDEX` に1件足す。`area` に領域IDを書く
3. 同じ領域の `planned` に同名があれば消す（残っていると点検で注意が出る）
4. 新しく出てくる会社を `companies.js` に足す
5. `node tools/build.js`

**領域を足す・直す**
`industries.js` の `SCM_AREAS` を編集する。領域IDは英小文字と数字だけ。業界の `area` が存在しない領域IDだと点検で止まる。

**業界どうしのつながりを足す**
1. `deps.js` に、`from`・`to`（業界IDと段ID）と `what`（何が流れるか）を1本足す
2. `node tools/build.js`（存在しない業界・段を指していると止まる）

業界ページ（全体と各段）とトップに自動で出ます。同じ会社が両方の業界にいる場合のリンクは、会社のページから自動で付くので、ここには書きません。

**会社を足す**
1. `companies.js` に共通情報を足す（すでにあれば不要）
2. 出てくる業界の `data/<業界ID>.js` の `companies` に `id`・`type`・`home`・`stages` を足す
3. `node tools/build.js`

企業ページは全社に自動でできます（出てくる業界と各段での役割、業界をまたぐリンク）。

**企業ページに概要や資本関係を上乗せする**
1. `pages/<会社ID>.js` を作る（`pages/jera.js` をまねる）
2. `companies.js` のその会社に `page: true` を足す
3. `node tools/build.js`

## データの決まり

- **数値は必須ではない。** 載せる業界だけ、業界ファイルで `showNumbers: true` にする
- **時価総額は月末の終値でそろえる。** 月末の値が取れない会社は、取れた日付を `capDate` に書く（ページ上で「時点違い」と表示される）
- **未上場企業は売上高で表示する。** 時価総額と同じ並びで比べるのは目安と注記する
- **金額の単位は億円。**（1兆円 = 10000）
- **不明なものは空欄にせず「未確認」と書く。**（出資額は `amount: null` で自動的に「出資額 未確認」と表示される）
- **資本関係の矢印は「出資する側 → 出資される側」。** 矢印には持ち株比率と出資額を書く
- **資本構成は簿価と時価を併記する。** 時価がないものは理由を `fvNote` に書く
- **`stages` が2つ以上ある会社は、自動で「段をまたぐ会社」の帯に出る。** 子会社が担う段も含めてよい（説明文に子会社名を書く）
- **業界をまたぐリンクは自動で付く。** 同じ会社IDが複数の業界ファイルにあればよい。まだページのない業種は `companies.js` の `otherSectors` に `href: null` で書く（「準備中」と表示される）
- **事実を足すときは出典を確認する。** 社名変更・上場廃止・TOBなどは `note` に時点つきで書く
